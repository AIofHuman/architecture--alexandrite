Текущие проблемы:
1.	Долгое время расчетов 3Д моделей
2.	Отсутствие кеша для типовых 3Д моделей, кеша для интернет магазина.
3.	Не оптимальная форма для списка новых заказов для операторов MES системы
4.	Отсутствует система мониторинга и трейсинга
5.	Нет подсистемы контроля за сроками исполнения заказов
6.	Отсутствует репликация для БД MES системы
Возможные будущие проблемы:
•	Рост заказов будет увеличивать нагрузку на базы данных
•	Рост предприятия потребует интеграцию ERP системы для управления возросшими платежами, возросшими материальными потоками, ростом штата компании
•	Рост компании и увеличение задач для отдела разработки потребует полной автоматизации процесса CI/CD

Предложения по развитию архитектуры ПО:

•	Внедрение кэширования результатов расчетов и информации о заказах
•	Улучшение интерфейса операторов MES системы  - (3-ая очередь)
•	Мониторинг производительности системы
Среднесрочные меры

•	Внедрения трейсинга для быстрого разбора ошибок и выявления узких мест
