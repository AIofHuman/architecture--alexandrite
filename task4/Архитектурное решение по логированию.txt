Логирование позволит нам, решить следующие проблемы:
•	Разбор ошибок происходит только на основе слов клиентов
•	Требуются значительные временные затраты на поиск причин проблем
•	Высокая нагрузка на службу поддержки
•	Отсутствие системного подхода к анализу проблем
Логирование предлагается настроить для всех API приложений, для бизнес-процесса по изменению статусов заказов настроить уровень логирования INFO. Для остальных процессов в продакте уровень логирования ERROR, для релиза DEBUG.
Алерты
•	DDOS атаки
•	Попытка загрузить большой файл модели
•	Аномальное число заказов в месяц (больше 3 сигма от среднего числа) от одного пользователя или компании.

Используем стек ELK – диаграмма представлена на рисунке jewerly_c4_model_logging.drawio.png

С точки зрения безопасности меры аналогичные трайсингу – авторизованный доступ и шифрование хранения логов.
